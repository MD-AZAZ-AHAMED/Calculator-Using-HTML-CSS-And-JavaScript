# Simple Calculator Web App

This is a basic, stylish calculator built with **HTML**, **CSS**, and **JavaScript**. It performs standard arithmetic operations and includes a user-friendly interface with button-based input.

![Calculator Screenshot](screenshot.png) <!-- Optional: add a screenshot in your repo -->

## ✨ Features

- Basic arithmetic operations: `+`, `-`, `*`, `/`
- Clear (`AC`) and delete last entry (`DE`)
- Supports decimal input
- Responsive and clean UI
- Visual feedback for operator buttons

## 🚀 How to Use


1. Open `index.html` in your web browser
2. Start calculating!

## 🧠 Code Highlights

- Uses `onclick` attributes for button interaction
- JavaScript logic is embedded inline using `eval()` for simplicity
- The display updates dynamically as you click buttons

> ⚠️ **Note:** `eval()` is used here for simplicity but can be unsafe for untrusted input. For real-world applications, consider safer expression evaluators.


## 💡 Future Improvements

- Keyboard input support
- Better expression validation without using `eval()`
- History of calculations
